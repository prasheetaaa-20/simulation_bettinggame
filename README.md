# simulation_bettinggame
Aim : To analyse the probability of the Indian betting game "Andar Bahar" by simulating 1million rounds using Python.
Game working : 
Andar Bahar is a popular Indian betting game. It involves:
1.Shuffling the deck and drawing a card that becomes the 'joker'. 
 2.The dealer then deals each card into 2 piles Bahar or Andar.
 3.The first pile to receive a card that matches the rank of the joker becomes the winning pile.

***important: Bahar is always dealt first, giving it a statistical advantage as we see through this simulation (usually the payout for Andar is more than Bahar to compensate)***

Project: The code simulates 1million rounds of the game and all the rounds' result are then used to find the probability of winning on each side.

Findings: Here are the results
Andar: 0.48445
Bahar: 0.51555

Conclusion : Clearly Bahar has a statistical advantage.
